# Ігри для компанії

Збірка настільних ігор на Android. Хост запускає застосунок, гравці один раз сканують QR —
і грають у браузері весь вечір, поки хост перемикає ігри. Встановлювати нічого не треба.

**Завантажити:** [останній реліз](https://github.com/sokolovskiy0103/party_games/releases/latest) → `PartyGames.apk`.

**Оновлення:** застосунок сам перевіряє GitHub при запуску (і з меню ☰ → «Перевірити оновлення»)
й ставить нову версію поверх старої, дані лишаються. Перший раз Android попросить дозволити
встановлення з цього джерела й підтвердити; на Android 12+ наступні оновлення йдуть без підтвердження.

## Як підключаються гравці

Перемикач на екрані хоста:

- **📶 Wi-Fi** — сервер працює на самому телефоні, гравці в тій самій мережі або на точці доступу хоста.
  Інтернет не потрібен.
- **🌍 Інтернет** — через ретранслятор на Render. Гравці можуть бути в будь-якій мережі,
  хоч на мобільному інтернеті; заходять за QR або вводять 4-літерний код на сайті ретранслятора.
  Сторінка відкривається по HTTPS, тож екрани гравців не гаснуть під час гри.

В обох режимах уся логіка гри — на телефоні хоста. Ретранслятор лише пересилає повідомлення
й роздає сторінку, яку бере з того ж телефону (версії завжди збігаються).

### Розгортання ретранслятора (один раз)

1. На [render.com](https://render.com): **New → Blueprint** → репозиторій `party_games`. `render.yaml` усе налаштує.
2. Якщо адреса вийшла не `https://party-games-relay.onrender.com` — у застосунку:
   «🌍 Інтернет» → «Адреса сервера» → встав свою.

Безкоштовний сервіс Render засинає після 15 хв без трафіку й прокидається до хвилини —
застосунок будить його сам, щойно увімкнеш «Інтернет».

## Архітектура

```
app/src/main/java/com/sokolovskiy/party/
  core/        Room (гравці, вибір гри), Hub (замок, стан, таймери),
               LocalServer (Ktor), RelayClient (WebSocket до Render), GameModule — контракт гри
  games/insider/  логіка + модуль
  games/herd/     логіка + опційний AI-суддя на ONNX
  games/hat/      логіка «Шляпи» (раунди, перенесення часу, статистика)
  games/wavelength/ логіка «Хвилі» (шкали, підказка, очки за відстань)
  games/chameleon/  логіка «Хамелеона» (теми, пари схожих слів, підказки по колу, голосування)
  games/ito/        логіка «Сотні» (рівні, життя, викладання карт)
  games/decrypto/   логіка «Шифру» (команди, коди, спільні чернетки відповідей, жетони)
  games/clocktower/ логіка «Кривавої вежі» (ролі, нічний порядок, інформація, номінації й голосування)
  update/      самооновлення: releases/latest → завантаження APK → PackageInstaller
app/src/main/assets/web/
  index.html, shell.js/css   — підключення, лобі, вибір гри, QR, перемикач мережі
  <game>.js/css              — екрани конкретної гри
relay/         Node-ретранслятор для Render (+ test.js)
```

### Як додати гру

1. `games/<id>/` — клас, що реалізує `GameModule` і `GameSession` (див. `core/GameModule.kt`):
   отримує гравців від кімнати, обробляє повідомлення, віддає стан **окремо для кожного глядача**.
2. Додати модуль у список у `core/Hub.kt`.
3. `assets/web/<id>.js` з `PG.register('<id>', { render, click, onState, menu })`, `<id>.css`,
   і підключити їх в `index.html`.

CI на кожен push у `main`: тест ретранслятора, unit-тести, підписаний APK і реліз `v1.0.<run>`.

## Локальна розробка без телефона

`dev/` запускає справжній `Hub` + Ktor-сервер на ПК (Android-класи замінені заглушками, «Стадо» — без ONNX).
Вебресурси читаються прямо з `app/src/main/assets/web/`, тож зміни в JS/CSS видно після F5.

```
.\gradlew :dev:run
```

Браузер сам відкриє сітку 2×2: хост («Хост») і ще троє гравців, усі вже приєднані. Кількість вікон:
`.\gradlew :dev:run --args="6"` (1–9). Кожне вікно сидить на своїй адресі `127.0.0.N`, тож має власний `localStorage`
і власну особу. Посилання хоста й гравців також друкуються в консолі (для справжнього телефона — IP ПК).
Параметр `?autojoin=Ім'я` у `shell.js` потрібен лише цьому лаунчеру. Зміни в Kotlin — Ctrl+C і запустити знову.
Потрібен лише JDK 17 (Gradle підтягнеться сам через wrapper; Android SDK не потрібен).
